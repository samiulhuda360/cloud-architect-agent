# Halvorsen Marine AS — cloud rules for project teams

Short version of the group security policy, for teams building on Azure. Ask the security team if anything is unclear.

**Data location.** Data covered by this policy must stay inside the EU/EEA.

**Encryption.** Use customer-managed keys (CMK) for all storage accounts and databases.

**Backups.** Backups: 90 days minimum retention.

**Logging.** Logs shall be retained for 400 days.

**Tagging.** Every resource must have the tags owner and project.

**Access.** Administrators sign in with phishing-resistant multi-factor authentication.
